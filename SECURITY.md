# Security policy / Политика безопасности

## Supported versions / Поддерживаемые версии

Security fixes are released for the latest version only. / Исправления безопасности выпускаются только для последней версии.

## Reporting a vulnerability / Сообщение об уязвимости

Please do not describe a vulnerability in a public issue. Use the private reporting form: [Security → Report a vulnerability](https://github.com/Juic3-me/Termimato/security/advisories/new). If the form is unavailable, write to [Telegram @vulp3s](https://t.me/vulp3s) or to vorcatch@gmail.com.

Не описывайте уязвимость в публичном issue. Используйте закрытую форму: [Security → Report a vulnerability](https://github.com/Juic3-me/Termimato/security/advisories/new). Если форма недоступна, напишите в [Telegram @vulp3s](https://t.me/vulp3s) или на vorcatch@gmail.com.

Include the version, a description of the problem and steps to reproduce it. You will get an answer within a week; the fix and its publication are agreed with the reporter. / Укажите версию, описание проблемы и шаги воспроизведения. Ответ придёт в течение недели, исправление и его публикация согласуются с автором сообщения.
